# Binary Trees

- Trees - Hierarchical DS.
- Binary Trees - Inside a guy, there can be at max 2 guys
- Root Node
- Children Nodes
- Leaf Node - A node which doesn't have any children
- Sub-Tree - A child Node acting as a Root node for subsequent nodes beneath
- Ancestors - All the parents, grandparents & great-grandparents of a node

Types of Binary Trees

- Full BT - Either has 0 or 2 children
- Complete BT - All levels are completely filled except the last level. The last level has all nodes to the left as possible. (Any node which is to the right of a parent node is NOT considered a Complete BT).
- Perfect BT - All leaf nodes are at the same level.
- Balanced BT - Height of tree at max: log(N), N -> number of nodes
- Degenerate Tree - Skewed trees, essentially serving as a Linked List
